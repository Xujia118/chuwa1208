**11. What is the spring security filter?**

In Spring Security, the security filter refers to the Spring Security filter chain — a series of Servlet filters that sit in front of your controllers and handle security concerns for every HTTP request.


Big picture

```
Client
  ↓
[ Spring Security Filters ]   ← authentication, authorization, CSRF, etc.
  ↓
[ DispatcherServlet ]
  ↓
[ Controller ]

```
