**8. Compare Session and Cookie**


| Aspect         | Cookie                           | Session                                        |
| -------------- | -------------------------------- | ---------------------------------------------- |
| Stored where   | **Client (browser)**             | **Server**                                     |
| What it stores | Small data (key-value strings)   | User state / objects                           |
| Identified by  | Sent automatically with requests | Usually by a **session ID stored in a cookie** |

Session almost always depends on cookies (or URL rewriting) to work.
