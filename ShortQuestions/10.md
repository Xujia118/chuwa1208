**What is cache stampede (also known as cache breakdown)? Describe two solutions to prevent it.**

Cache stampede (also called cache breakdown) is a situation where many concurrent requests try to access the same data at the same time, and that data either expires or is evicted from the cache. When the cached entry is no longer available, all incoming requests “fall through” to the backend (e.g., database or downstream service) simultaneously. This creates a sudden spike of load on the backend, which can overwhelm it, increase latency dramatically, or even cause cascading failures. Cache stampede typically happens with hot keys—data that is requested very frequently—especially when the cache uses a fixed TTL and the item expires at once.

One common solution is mutex locking (or single-flight request control). When the cache entry expires and multiple threads attempt to rebuild it, only one thread is allowed to fetch and recompute the data from the backend. The others wait for that thread to finish and then read the refreshed value from the cache. This can be implemented using distributed locks (e.g., Redis-based locks) in distributed systems or in-memory locks in a single-instance system. By ensuring only one request rebuilds the cache, you prevent a thundering herd of requests from hitting the database at the same time.

Another effective solution is adding randomized expiration (TTL jitter) or using logical expiration with background refresh. Instead of giving all cached entries the exact same TTL (e.g., 10 minutes), you add a small random offset so they expire at slightly different times. This reduces the chance that many hot keys expire simultaneously. Alternatively, with logical expiration, the cache stores both the data and an expiration timestamp. When the data is logically expired, one request triggers an asynchronous refresh in the background while other requests temporarily continue to serve stale data. This approach maintains availability and smooths backend load, significantly reducing the risk of a stampede.
