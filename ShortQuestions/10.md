**How do we use session and cookie to keep user information across the the application?**

Basic flow

1.  First request (no session yet)

```
Client → Server: GET /login
```

Server:

- Creates a new session object

- Generates a unique sessionId

- Stores session data in memory / Redis / DB

Server responds:

```
Set-Cookie: JSESSIONID=abc123; HttpOnly; Secure

```

2. Client stores session id

```
JSESSIONID=abc123

```

3. Subsequent requests

```
Client → Server:
Cookie: JSESSIONID=abc123

```

Server:

- Reads session ID

- Looks up session data

- Restores user context
