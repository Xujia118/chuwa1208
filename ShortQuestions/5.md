**What is the formula for calculating optimal thread pool size? How would you size a thread pool for: A CPU-bound task on an 8-core machine? An I/O-bound task where wait time is 100ms and compute time is 5ms?**


The classic formula for estimating optimal thread pool size comes from Java Concurrency in Practice by Brian Goetz. It is:

```
Optimal Threads=Number of CPU Cores×Target CPU Utilization×(1+Compute TimeWait Time​)

```


- CPU-Bound Task on an 8-Core Machine

For CPU-Bound Task, wait time is approximately zero. 

The formula simplifies to: Threads=Cores×TargetUtilization

If we assume near 100% CPU utilization: Threads=8×1.0=8

So the optimal thread pool size is 8 threads.


- I/O-Bound Task (Wait = 100ms, Compute = 5ms)

threads = 8 x 1.0 x (1 + 100 / 5) = 8 x 21 = 168

Note this is a bad use of threads. We should use a single thread with async non-blocking.
