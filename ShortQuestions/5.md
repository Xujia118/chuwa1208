**5. Compare authentication and authorization? Name and explain important components in Spring security that undertake authentication and authorization**

Authentication vs Authorization (quick refresher)

Authentication → Who are you? (identity verification: login, token, credentials)

Authorization → Are you allowed to do this? (permissions, roles, ownership)

Table summary:

| Aspect            | Authentication                               | Authorization                     |
| ----------------- | -------------------------------------------- | --------------------------------- |
| Question answered | **Who are you?**                             | **What are you allowed to do?**   |
| Happens when      | First                                        | After authentication              |
| Input             | Credentials (username/password, token, cert) | User identity + roles/authorities |
| Output            | An authenticated `Principal`                 | Permit or deny access             |
| Failure result    | 401 Unauthorized                             | 403 Forbidden                     |


Core Spring Security Components (Big Picture Flow)

```
Spring Security is filter-based. Everything important happens inside the filter chain.

Request
 → SecurityFilterChain
   → Authentication
   → Authorization
 → Controller

```

Authentication Components in Spring Security

1. SecurityFilterChain

Entry point for Spring Security. Decides which authentication mechanism is applied

Contains filters like:

- UsernamePasswordAuthenticationFilter

- BearerTokenAuthenticationFilter

```
@Bean
SecurityFilterChain filterChain(HttpSecurity http) throws Exception {
    http
        .authorizeHttpRequests(...)
        .httpBasic();
    return http.build();
}

```

2. Authentication

Represents the current user

Holds:

- principal (user)

- credentials

- authorities

- authenticated flag

```
Authentication auth = SecurityContextHolder.getContext().getAuthentication();

```

3. uthenticationManager

- Orchestrator

- Delegates authentication to AuthenticationProviders

```
Authentication authenticate(Authentication authentication);

```

4. AuthenticationProvider

Does the actual authentication

Examples:

DaoAuthenticationProvider

JwtAuthenticationProvider

```
boolean supports(Class<?> authentication);
Authentication authenticate(Authentication authentication);

```

5. UserDetails

Loads user data from DB / API

```
@Service
public class UserDetailsServiceImpl implements UserDetailsService {
    public UserDetails loadUserByUsername(String username) {
        return userRepository.findByUsername(username)
            .orElseThrow(() -> new UsernameNotFoundException(username));
    }
}

```

6. UserDetails

Spring Security’s user model

Contains:

- username

- password

- authorities

- account status

7. PasswordEncoder

Compares raw password with stored hash

8. SecurityContext / SecurityContextHolder

Stores authenticated user for the request lifecycle

Authorization Components in Spring Security

1. GrantedAuthority

Represents permissions

```
ROLE_USER
ROLE_ADMIN
task:read
task:delete

```

2. AccessDecisionManager

Decides allow or deny

Evaluates:

- authentication

- authorities

- request

3. AuthorizationManager

Newer, simpler, functional API (Spring Security 6+)

```
authorizeHttpRequests(auth -> 
    auth.requestMatchers("/admin/**").hasRole("ADMIN")
)

```

4. Method Security Annotations

```
@EnableMethodSecurity

@PreAuthorize("hasRole('ADMIN')")
@PreAuthorize("#userId == authentication.principal.id")
@Secured("ROLE_USER")

```

5. FilterSecurityInterceptor

Final gate before controller execution

Enforces authorization rules
