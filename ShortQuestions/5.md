**Explain following concept in your own words, you may include code snippet as part of your answer.**

1. Aspect

Tthe "module" that packages everything above together. It is a class that contains your PointCuts (where to do it) and your Advice (what to do).

2. PointCut

A set of rules used to select which JoinPoints you actually want to target.

3. JoinPoint

A specific point in the execution of your application where an action could be taken.

4. Advice

The action to take


```
@Aspect
@Component
public class LoggingAspect { // THE ASPECT: The container for our cross-cutting logic

    // THE POINTCUT: This targets any method in the 'service' package
    @Pointcut("execution(* com.myapp.service.*.*(..))")
    public void serviceLayerMethods() {}

    // THE ADVICE: This is the 'what'. We are using 'Before' advice here.
    // The 'JoinPoint' parameter gives us access to details about the method being called.
    @Before("serviceLayerMethods()") 
    public void logBefore(JoinPoint joinPoint) { 
        System.out.println("ADVICE: Starting execution of: " + joinPoint.getSignature().getName());
    }
}
```
