**Explain the four common metric types and give an example use case for each.**

Counter

A Counter is a metric that only increases over time (or resets to zero on restart). It is used to measure the total number of occurrences of an event. Counters are ideal for tracking things like the number of HTTP requests served, the total number of errors, or the number of completed tasks. For example, in a web application, you might use a counter called http_requests_total to record how many requests your server has processed. From this, you can calculate request rates (e.g., requests per second) and error ratios.

Gauge

A Gauge represents a value that can go up or down. It reflects the current state of something at a given moment in time. Gauges are useful for measuring quantities like memory usage, CPU utilization, queue length, or the number of active users. For instance, you might use a gauge called active_sessions to track how many users are currently logged in. Since users can log in and log out, the value naturally increases and decreases.

Histogram

A Histogram measures the distribution of values by grouping observations into configurable buckets. It is commonly used to track request durations, response sizes, or other performance-related metrics. For example, a metric like http_request_duration_seconds can record how long each request takes and categorize them into latency buckets (e.g., under 100ms, 200ms, 500ms, etc.). This allows you to compute percentiles such as the 95th percentile latency, which is critical for understanding system performance.

Summary

A Summary is similar to a histogram in that it tracks distributions and provides quantiles (such as median or 99th percentile). However, summaries calculate quantiles directly on the client side rather than relying on server-side aggregation. This makes them useful when you need accurate quantiles for a single instance. For example, you might use a summary to track database query latency within a specific service instance. The trade-off is that summaries are harder to aggregate across multiple instances compared to histograms.
