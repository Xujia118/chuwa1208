**6. Explain HTTP Session?**

An HTTP Session is a way for a server to remember a client across multiple HTTP requests, even though HTTP itself is stateless.

Why HTTP Session exists

HTTP is stateless:

- Each request is independent

- Server does not remember previous requests

But real applications need state:

- User login

- Shopping cart

- User preferences

- Multi-step forms

An HTTP session is:

A server-side storage of user-specific data

- Identified by a session ID

- Linked to the client via a cookie (usually)
