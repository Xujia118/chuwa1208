**14. Compare UserDetailService, AuthenticationProvider, AuthenticationManager, AuthenticationFilter?**

1. UserDetailsService

Type: Interface

- Purpose: Loads user-specific data.

- Method: UserDetails loadUserByUsername(String username) throws UsernameNotFoundException

- Responsibilities:

- Given a username (or another identifier), fetch the user from your database or other store.

- Return a UserDetails object containing:

    - Username

    - Password (usually hashed)

    - Authorities/Roles

    - Account status flags (locked, expired, enabled)

```
@Service
public class MyUserDetailsService implements UserDetailsService {
    private final UserRepository userRepository;

    public MyUserDetailsService(UserRepository repo) {
        this.userRepository = repo;
    }

    @Override
    public UserDetails loadUserByUsername(String username) throws UsernameNotFoundException {
        User user = userRepository.findByUsername(username)
                        .orElseThrow(() -> new UsernameNotFoundException("User not found"));
        return new org.springframework.security.core.userdetails.User(
                user.getUsername(),
                user.getPassword(),
                user.getRoles()
        );
    }
}

```

2. AuthenticationProvider

- Type: Interface

- Purpose: Actually performs authentication logic.

- Method: Authentication authenticate(Authentication authentication) throws AuthenticationException

- Responsibilities:

    - Take an Authentication token (usually username + password).

    - Verify the credentials.

    - If successful, return a fully populated Authentication object (with authorities, etc.).

    - If failed, throw an AuthenticationException.


3. AuthenticationManager

- Type: Interface (usually auto-configured by Spring Security)

- Purpose: Delegates authentication requests to one or more AuthenticationProviders.

- Method: Authentication authenticate(Authentication authentication) throws AuthenticationException

- Responsibilities:

    - Acts as a coordinator.

    - Tries multiple AuthenticationProviders until one succeeds or all fail.


```
public class ProviderManager implements AuthenticationManager {
    private List<AuthenticationProvider> providers;

    public Authentication authenticate(Authentication auth) {
        for (AuthenticationProvider provider : providers) {
            if (provider.supports(auth.getClass())) {
                return provider.authenticate(auth);
            }
        }
        throw new BadCredentialsException("Authentication failed");
    }
}

```

4. AuthenticationFilter

- Type: Servlet Filter

- Purpose: Intercepts HTTP requests and attempts authentication.

- Responsibilities:

    - Extracts credentials from the request (e.g., username/password from a login form, or JWT from a header).

    - Builds an Authentication token.

    - Calls AuthenticationManager.authenticate().

    - On success, stores the authenticated Authentication in SecurityContext.

    - On failure, returns 401/403 or redirects to login page.

```
Incoming HTTP request --> AuthenticationFilter
    -> Extract credentials --> Build token
    -> Pass token to AuthenticationManager
        -> Delegates to AuthenticationProvider(s)
            -> Calls UserDetailsService to load user
            -> Verifies credentials
            -> Returns authenticated token
    -> On success, save in SecurityContext

```
