**3. What are the advantages and disadvantages of Spring AOP?**

Advantages

- Better Modularity (Separation of Concerns): This is the primary benefit. By moving cross-cutting concerns (logging, security, transactions) into Aspects, your business logic remains clean, readable, and focused solely on its primary task.

- Code Reusability (DRY Principle): You write the logic for a concern once (e.g., an audit log) and apply it to hundreds of methods via a single Pointcut expression.

- Centralized Management: If you need to update your security logic or change how exceptions are logged, you only have to modify one class. This significantly reduces the risk of bugs when making global changes.

- Improved Maintainability: Because the "boilerplate" code is removed from the service layer, the codebase is smaller and easier for new developers to understand.

- Declarative Programming: It allows developers to use simple annotations (like @Transactional) to implement complex features without needing to know the low-level implementation details of the underlying infrastructure.

Drawbacks

- Increased Complexity (Debugging Hurdles): Since the code execution "jumps" into an Aspect that isn't explicitly called in your service method, it can be difficult for developers to follow the program flow. Debugging stack traces becomes much longer and more confusing.

- Performance Overhead: Because Spring AOP relies on Proxies, every method call must go through an extra layer. While the overhead is usually negligible (milliseconds), in high-frequency, low-latency systems, it can add up.

- "Self-Invocation" Issue: This is a famous Spring AOP "gotcha." If method A() in a service calls method B() in the same service, the Aspect on method B() will not trigger. This is because the call doesn't go through the Proxy; it's a direct internal call.

- Runtime Dependency: Spring AOP is a "Proxy-based" framework. It only works on methods of objects that are managed as Spring Beans. It cannot intercept methods in classes created with the new keyword or private/static methods.

- Learning Curve: Understanding Pointcut expressions (AspectJ expression language) and the lifecycle of Join Points requires a specific set of skills that goes beyond standard Java/OOP knowledge.
