**What is a vector clock? How does it determine whether two events are causally related or concurrent? Why can't we simply use physical timestamps instead?**


1. What is a Vector Clock?

A vector clock is an array (or vector) of $N$ logical counters, where $N$ is the number of nodes in the system. Each node $i$ maintains its own vector $V$, where $V[i]$ is its own local logical time.

How it works:
- Initialization: Every node starts with a vector of zeros: $[0, 0, 0, \dots, 0]$.
- Local Event: When a node performs an internal action, it increments its own entry in its vector: $V[i] = V[i] + 1$.
- Sending a Message: The node increments its own counter and attaches its entire vector to the message.
- Receiving a Message: When node $j$ receives a message with vector $V_{msg}$, it updates its local vector $V_{local}$ by taking the element-wise maximum of both vectors:$$V_{local}[k] = \max(V_{local}[k], V_{msg}[k]) \quad \text{for all } k$$

Then, it increments its own entry: $V_{local}[j] = V_{local}[j] + 1$.


2. Determining Causality vs. Concurrency

Vector clocks allow us to compare two events, $A$ and $B$, by comparing their vectors $V(A)$ and $V(B)$.

- Causally Related ($A \to B$): Event $A$ happened before event $B$ if every element in $V(A)$ is less than or equal to the corresponding element in $V(B)$, and at least one element is strictly smaller.$$V(A) < V(B) \iff \forall i: V(A)[i] \le V(B)[i] \land \exists j: V(A)[j] < V(B)[j]$$This means $B$ "knows" about everything that happened in $A$.

- Concurrent ($A \parallel B$): If neither $V(A) < V(B)$ nor $V(B) < V(A)$ is true, the events are concurrent.


3. Why not use physical timestamps?

- Clock skew: Physical clocks on different machines are never perfectly synchronized. Even small drifts can violate causal order.

- Non-determinism: Network delays and process scheduling mean that "earlier timestamp" doesn’t imply "happened-before."

- Causality vs. real time: We care about logical order of events, not when they were physically observed.

Example: Two nodes do work concurrently. Even if node A’s clock says 10:01 and node B’s says 10:00, we cannot conclude A → B or B → A. Vector clocks capture this properly.
