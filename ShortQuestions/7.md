**7. Compare different types of advices in Spring AOP.**

1. @Before
Runs before the target method is invoked. It cannot stop the execution flow of the target method unless it throws an exception (e.g., a SecurityException if the user is unauthorized).


2. @AfterReturning
Runs after the target method completes successfully. You can access the returned value using the returning attribute in the annotation, though you cannot modify the value before it reaches the caller.


3. @AfterThrowing
Runs if the target method exits by throwing an exception. This is useful for centralizing error logic. You can capture the exception object using the throwing attribute.


4. @After (Finally)
Think of this as the finally block in a try-catch. It runs regardless of whether the method succeeded or failed. It is usually used for cleaning up resources to prevent leaks.


5. @Around
The most powerful and flexible advice. It surrounds the target method and gives you control over:

Whether to execute the target method at all (by calling joinPoint.proceed()).

Modifying the input arguments before they reach the method.

Modifying the return value or catching exceptions before the caller sees them.

Warning: While @Around can do everything the other advices do, Spring recommends using the most specific advice type possible (e.g., use @Before if you only need pre-checks) to keep the code simpler and less prone to errors like forgetting to call proceed().
