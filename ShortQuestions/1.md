**1. List all of the annotations you learned from class and homework to annotaitons.md**

@Aspect: Marks the class as a collection of AOP rules.

@Before: Runs before the target method starts. Used for logging or security checks.

@After: Runs after the method completes, regardless of whether it succeeded or threw an exception (like a finally block).

@AfterReturning: Runs only if the method completes successfully. You can access the returned value here.

@AfterThrowing: Runs only if the method throws an exception. You can access the exception object here.

@Around: The most powerful advice. It surrounds the method call, allowing you to manage the start, the end, and even skip the method execution entirely.

@Pointcut: Used to define a reusable pointcut expression. Instead of repeating "execution(* com.myapp.service.*.*(..))" in every advice, you define it once on a dummy method and reference that method name.
